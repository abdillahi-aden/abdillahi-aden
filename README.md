## Portfolio SIG

### [CycloTrip — planification d’itinéraires cyclables](https://github.com/abdillahi-aden/projet-cyclotrip)

Application **Python / Streamlit** de planification d’itinéraires cyclables : recherche d’adresses dans PostgreSQL, itinéraires via OpenRouteService, recherche de points d’intérêt par proximité avec **PostGIS**, carte **Folium**, traitements géométriques **Shapely** et exports GPX / GeoJSON. Le dépôt contient des tests unitaires et un workflow GitHub Actions.

[Consulter l’application](https://cyclotrip-france.streamlit.app/) · [Documentation et prérequis](https://github.com/abdillahi-aden/projet-cyclotrip#readme)

### [Observatoire des aménagements cyclables — Montreuil](https://github.com/abdillahi-aden/observatoire_amenagement_cyclables)

Tableau de bord cartographique en **JavaScript**, avec **Leaflet**, **Chart.js** et **Turf.js**. Il combine des GeoJSON publics hébergés sur **ArcGIS Online**, des copies locales de secours, des filtres et des indicateurs sur les aménagements et les stationnements cyclables.

[Consulter la démonstration](https://abdillahi-aden.github.io/observatoire_amenagement_cyclables/) · [Documentation et sources](https://github.com/abdillahi-aden/observatoire_amenagement_cyclables#readme)
